# 📱 PhoneMic · 把手机当电脑的临时麦克风

[English](README.en.md) · **简体中文**

手机扫码打开一个网页，点一下按钮，手机就开始给电脑「供音」：

- **局域网**：电脑起一个服务，手机扫二维码直接连，声音从电脑声卡放出来。
- **游戏麦克风**：加 `--mic` 自动把声音送进虚拟声卡，游戏里把麦克风选成 `CABLE Output`，队友就能听见你（见第二节）。
- **公网**：加 `--tunnel` 自动开一个 `https://xxx.trycloudflare.com` 的公网链接，人在外面也能用手机给家里的电脑喂声音。
- **零原生依赖**：不用装驱动、不用 WebRTC、不用 ffmpeg。音频输出用 Windows 自带的 .NET 编译器现场生成一个小程序；只有游戏麦克风模式需要一块免费的虚拟声卡。

> 手机浏览器规定：**只有 https 页面才允许调用麦克风**。所以局域网用的是自签名证书，第一次连的时候手机会提示「不安全」，点继续就好（见下文）。

界面支持**中文 / 英文**：网页右上角点 `EN / 中文` 切换（会记住选择）。控制台文字跟随系统语言，也可以用 `--lang zh` / `--lang en` 强制指定。

## 一、跑起来

需要 Node.js 18 以上（`node -v` 能出结果就行）。

**三种启动方式，任选一种：**

1. **双击 `start.bat`**（推荐）。首次会自动装依赖，窗口会一直留着显示二维码。
2. **用 VS Code 打开这个文件夹，按 F5**。已内置调试配置，下拉框里还能直接选「查看可用播放设备」「假手机测试」。
3. 命令行：

   ```bat
   cd PhoneMic
   npm install
   node server.js
   ```

启动后终端会打印一个二维码和地址，手机扫一下（或手动输入）就能进：

```
   手机扫码或直接打开：
   https://192.168.1.34:8443/?k=1b9d0f8d

       ██████████████    ██  ██  ██    ████
       ██          ██  ████  ████  ████████
       ...

   电脑控制台： http://127.0.0.1:8081/dash
   音频输出：   电脑声卡 48 kHz
```

电脑会自动弹出控制台页面（`/dash`），里面有放大的二维码、当前连了几台手机、每台的电平条和缓冲状态。

### 手机上要做的三步

1. 扫码打开页面。
2. 浏览器提示「您的连接不是私密连接」→ **高级 → 继续前往**（这是自签名证书的正常提示，只影响这一次）。
3. 点中间那个大话筒按钮，允许使用麦克风。**开始收音了。**

想要停止就再点一次。

## 二、变成游戏 / 会议麦克风（让别人听见你）

默认声音从电脑音箱出来，只能自己听见。要让**游戏、开黑软件、腾讯会议、OBS**把手机当成麦克风，需要一块虚拟声卡，把声音从「播放端」绕进「录音端」：

```
手机 → PhoneMic → CABLE Input（虚拟声卡播放端）
                        │ 驱动内部直通
                        ▼
游戏麦克风 ← CABLE Output（虚拟声卡录音端）
```

### 1. 安装 VB-Audio Virtual Cable（只需一次）

1. 打开 <https://vb-audio.com/Cable/>，下载 `VBCABLE_Driver_Pack*.zip`。
2. 解压，右键 `VBCABLE_Setup_x64.exe` → **以管理员身份运行** → `Install Driver`。
3. **重启电脑**（装声卡驱动必须重启）。
4. 确认「声音设置 → 播放」里多出了 `CABLE Input (VB-Audio Virtual Cable)`。

> ⚠ 装完后 Windows 可能把默认播放设备自动切成 CABLE Input。请手动把**默认播放设备改回耳机/音箱**，否则游戏声音会一起被送进麦克风，队友会听到你的游戏声。

### 2. 用游戏麦克风模式启动

双击 **`start-mic.bat`**（推荐），或者：

```bat
node server.js --mic
```

程序会自动找到 `CABLE Input` 并把声音送进去，终端会显示：

```
   📱 PhoneMic · 手机当临时麦克风 · 游戏麦克风模式
   音频输出：   游戏麦克风 → [3] CABLE Input (VB-Audio Virtual Ca
   ✅ 游戏麦克风已就绪。在游戏 / 开黑软件里把「麦克风」设为：
      CABLE Output (VB-Audio Virtual Cable)
```

没装虚拟声卡时不会硬撑，会直接打印安装步骤然后退出。

> 启动时如果检测到 Windows 的「默认播放 / 默认通信播放」被设成了虚拟声卡，程序会直接警告。照着提示把默认输出改回耳机 / 音箱，否则游戏声音会混进麦克风，形成「桌面声音」和回声。改完可以 `node server.js --doctor` 复查。

### 3. 在游戏里选麦克风

游戏 → 设置 → 音频 / 语音 → **麦克风 / 输入设备**：

```
CABLE Output (VB-Audio Virtual Cable)
```

不要选「立体声混音 / Stereo Mix」，那会把电脑所有声音都当成麦克风。选好后进游戏的语音测试（设置里一般都有麦克风试音条），手机说话时应该能看到电平在跳。

> 小技巧：也可以在 Windows「声音设置 → 更多声音设置 → 录制」里把 `CABLE Output` 设为**默认设备**和**默认通信设备**，这样所有游戏/语音软件都会自动用它，不用一个个去选。

### 4. 可选：自己也想听见

```bat
start-mic.bat --monitor
```

会用**系统默认扬声器**同步播放一份。也可以指定设备：

```bat
start-mic.bat --monitor "Razer"
```

注意监听会有约 100–150 ms 延迟，长时间说话容易节奏错乱；打游戏建议戴耳机、不开监听，或者只把耳机戴一只。

### 5. 用别的虚拟声卡

VoiceMeeter、Virtual Audio Cable、Voicemod 也可以，程序会自动识别常见名字；识别不到就手动指定：

```bat
node server.js --cable "设备名片段"
```

`node server.js --list-devices` 里带 `←` 标记的就是可用的虚拟声卡。

> 会议软件的用法完全一样：麦克风选 `CABLE Output`。电脑音箱不会响，也不会有啸叫。

## 三、公网访问（不在同一个 Wi-Fi 时）

### 方式 A：自动开隧道（最简单）

```bat
winget install --id Cloudflare.cloudflared
node server.js --tunnel
```

启动后会自动多出一个 `https://xxx-xxx.trycloudflare.com` 的地址，二维码也会自动换成这个。它是**正规 HTTPS 证书**，手机不会弹任何警告，用 4G/5G 也能连。

> 免费隧道每次启动地址都会变，而且速度不如局域网。日常用还是推荐同一个 Wi-Fi 下直连。

### 方式 B：自己已经有域名/反向代理

```bat
node server.js --public-url https://mic.example.com/
```

把反向代理指到 `http://127.0.0.1:8080`（记得要转发 WebSocket 升级）。

## 四、常用参数

| 参数 | 说明 |
| --- | --- |
| `--port <n>` | 局域网 HTTPS 端口，默认 `8443` |
| `--http-port <n>` | 本机 HTTP 端口，默认 `8080`（给隧道/调试用） |
| `--mic` | 游戏麦克风模式：自动找到虚拟声卡并输出过去 |
| `--cable <名字\|序号>` | 手动指定虚拟声卡（隐含 `--mic`） |
| `--monitor [名字\|序号]` | 同时从另一台设备播放给自己听，省略名字=系统默认 |
| `--device <名字\|序号>` | 不用虚拟声卡时，输出到哪块声卡（`--list-devices` 查看） |
| `--latency <ms>` | 抖动缓冲，默认 `120`。Wi-Fi 差/老路由器可调到 `200` |
| `--player <模式>` | `native` 声卡（默认）/ `browser` 浏览器播放 / `none` 只录不播 |
| `--record <文件.wav>` | 顺手把收到的声音录成 WAV |
| `--token <字符串>` | 自定义访问口令，`--no-token` 关闭口令 |
| `--tunnel` | 用 cloudflared 开公网地址 |
| `--public-url <url>` | 手动指定对外地址 |
| `--ip <地址>` | 多网卡时指定用哪个 IP 生成二维码 |
| `--lang <zh\|en\|auto>` | 界面语言，默认 `auto` 跟随系统 |
| `--no-open` | 不自动打开控制台网页 |
| `--list-devices` | 列出播放 / 录音设备，并标出 Windows 默认设备和虚拟声卡 |
| `--doctor` | 体检：默认播放/录音设备会不会把桌面声音混进麦克风 |

例子：

```bat
:: 游戏麦克风 + 自己也能听见
node server.js --mic --monitor

:: 录音 + 降低延迟 + 指定声卡
node server.js --record 会议.wav --latency 90 --device 1

:: 不想让别人乱连，自己定个口令
node server.js --token mysecret
```

## 六、常见问题

**麦克风里全是桌面声音 / 队友听到游戏声和回声？**
这是 Windows 默认设备被虚拟声卡占用了，不是 PhoneMic 在采集桌面。先跑一次体检：

```bat
node server.js --doctor
```

它会打印 Windows 当前的 4 个默认设备，并指出问题。最常见的两种：
- **「默认通信播放设备」是 `CABLE Input`**：游戏、Discord、音乐的声音全部流进虚拟声卡，再从 `CABLE Output` 出来，别人就听到你的桌面声音（还会来回循环）。
- **「默认麦克风」是 `立体声混音 / Stereo Mix`**：它录的就是电脑正在播放的声音。

修复（需要改 Windows 设置，程序不能替你点）：
1. `Win+R` → 输入 `mmsys.cpl` → 回车
2. 「播放」标签：右键你的耳机 / 音箱 → **设为默认设备**，再右键 → **设为默认通信设备**
3. 「录制」标签：右键 `CABLE Output (VB-Audio Virtual Cable)` → **设为默认设备**，再右键 → **设为默认通信设备**
4. 重新跑 `node server.js --doctor`（或双击 `doctor.bat`）复查

控制台 `/dash` 顶部也会用醒目提示显示同样的问题，并带一个「打开声音控制面板」按钮。

**外放时出现循环啸叫 / 诡异的声音？**
手机麦克风听到了电脑音响，形成「手机 → 电脑 → 音响 → 手机」的声学循环。
- 打游戏：用 `start-mic.bat`，声音只进虚拟声卡，不从音响放。
- 一定要自己听：用 `--monitor` 但**必须戴耳机**，不要外放。
- 临时外放：把音量调小、手机离音响远一点，并保持手机页面「回声消除」开启。

**游戏里队友听不见我？**按顺序检查：
1. 游戏里的「麦克风 / 输入设备」是否选了 **`CABLE Output (VB-Audio Virtual Cable)`**，不是扬声器、不是 Stereo Mix。
2. 手机页面是否已经点了话筒按钮（控制台里能看到这台手机、电平条会动）。
3. Windows 设置 → 隐私和安全性 → 麦克风 → 允许桌面应用访问麦克风。
4. 游戏里的麦克风音量/增益是不是 0；有些游戏默认把「语音激活」阈值设得很高。
5. 有没有别的软件独占了 CABLE Output（比如另一个会议软件），关掉它。
6. 用 `start-mic.bat --monitor` 听一下：如果监听里有声音，说明 PhoneMic 这边没问题，问题出在游戏的设备选择。

**装了虚拟声卡后电脑自己没声音了？**
Windows 把默认播放设备切到了 `CABLE Input`。去「声音设置」把默认播放设备改回耳机/音箱。PhoneMic 是按设备名直接输出的，不依赖系统默认设备。

**监听（--monitor）有回声/延迟？**
这是正常的：监听走的是另一块声卡，约 100–150 ms 延迟。打游戏建议不开监听，或者戴耳机只戴一只。手机页面保持「回声消除」打开。

**双击 start.bat 窗口一闪就没了？**
已修复。原因是批处理文件里混进了 UTF-8 中文和 LF 换行，cmd.exe 按本地代码页（GBK）去解析时会把中文读成乱七八糟的命令，脚本还没走到结尾的 `pause` 就退出了。

现在 `start.bat` 是**纯 ASCII + CRLF**，任何代码页下都不会出问题，结尾一定会停在「Press any key to close this window」。中文提示由 Node 自己打印，不受控制台代码页影响。

顺手记个坑：以后自己写 `.bat`，要么存成 ANSI/GBK，要么别放中文——千万别存成 UTF-8。

**手机提示「不安全」不敢点？**
自签名证书必然如此。如果你介意，用 `--tunnel` 或 `--public-url` 走正规证书。

**点话筒没反应 / 提示需要 https？**
一定是用了 `http://` 的地址。手机浏览器只在 https（或本机 localhost）下给麦克风权限。

**电脑没声音？**
1. `node server.js --list-devices` 看看是不是输出到了没接的音箱（比如显示器 HDMI）。
2. `--device "Realtek"` 之类指定一块。
3. Windows 音量合成器里确认 node 的音量没被静音。

**声音断断续续？**
把 `--latency` 调到 200；确认手机和电脑在同一个 5G Wi-Fi；控制台页面里看那台手机的「断续」次数和缓冲毫秒数。

**有回声/啸叫？**
手机离电脑音箱太近。手机页面「声音设置」里保持**回声消除**打开，把电脑音量调小，或者干脆用耳机 / 走虚拟声卡的方案。

**手机锁屏就断了？**
这是手机浏览器的限制，页面会申请屏幕常亮（Wake Lock），但部分省电模式下仍会被杀掉。保持页面在前台即可。

**局域网连不上？**
Windows 防火墙第一次会弹窗，选「允许」。如果当时点了取消：
```bat
netsh advfirewall firewall add rule name="PhoneMic 8443" dir=in action=allow protocol=TCP localport=8443
```
（需要管理员权限）

**端口被占用？**
会自动往后找（8443 → 8444…），终端会打印实际地址。注意 8080 经常被别的软件占，无所谓的。

**换电脑 / 换网络后手机连不上？**
证书里绑定了 IP，IP 变了要删掉 `certs/` 目录让它重新生成。

## 七、它是怎么工作的

```
 手机浏览器
   ├─ getUserMedia 拿到麦克风
   ├─ AudioWorklet 切成 20ms 的 Int16 帧（在主线程之外，不卡）
   └─ WebSocket 二进制帧 ─────────────┐
                                      ▼
                             Node 服务（server.js）
                               ├─ 每路一个抖动缓冲（默认 120ms），先垫满再播
                               ├─ 采样率不一致就线性插值重采样
                               ├─ 多台手机同时进来就混音
                               └─ 按声卡的实际播放节拍投喂（应答式，不堆延迟）
                                      ▼
                            build/audiosink.exe（csc 现场编译）
                               ├─ waveOut 双缓冲 → 声卡
                               └─ --mic：→ CABLE Input → 游戏麦克风选 CABLE Output
                                  --monitor：同一帧再送一块声卡（跟不上就丢帧）
```

两个关键设计：

1. **应答式投喂**：声卡程序每播完一块就往 stdout 写一个字节，Node 收到才发下一块。这样管道里永远只有 1～2 块数据，不会像「一股脑写进去」那样攒出几百毫秒延迟。
2. **30ms 缓冲块**：实测 Windows 共享模式下 20ms 的 waveOut 缓冲每块会被驱动多拖 ~5ms（播放速度只有实时的 80%），30ms 以上就正好实时。所以手机端发 20ms 小块，服务端攒成 30ms 再送声卡。

```

├─ lib/i18n.js          控制台文字的中英文案

│  ├─ index.html        手机端页面（麦克风采集）
│  ├─ worklet.js        采集用的 AudioWorklet

│  ├─ dash.html         电脑控制台（二维码/电平/连接状态）
│  └─ monitor.html      用浏览器播放声音（不想占用声卡时用）

├─ certs/               自动生成的自签名证书
├─ build/               自动生成的 audiosink.exe
├─ start.bat            双击启动（普通外放模式）
├─ start-mic.bat        双击启动（游戏麦克风模式）
├─ doctor.bat           双击检查 Windows 音频路由（桌面声音有没有混进麦克风）
├─ README.md            中文说明（本文件）
└─ README.en.md         English documentation
```

## 九、隐私说明

- 声音只在「电脑 ↔ 手机」之间直连，不经过任何第三方服务器（除非你自己开了隧道）。
- 默认每次启动生成一个随机口令，不在网址里就进不来。
- 不开 `--record` 就不会在硬盘上留下任何音频。
